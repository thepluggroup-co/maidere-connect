# Maidere: Local Services

https://maideres.lovable.app

Je veux un prompt Lovable qui génère un site web vitrine professionnel pour la plateforme MAIDERE.

Contexte de la plateforme:

- **Nom:** MAIDERE

- **Slogan:** "Tous les services près de chez vous"

- **Localisation:** Côte d'Ivoire

- **Devise:** XOF (FCFA)

- **Couleurs de marque:** Bleu marine primaire (#1B2A5E), vert secondaire (#3DAE2B), palette de couleurs complémentaires (bleu clair, orange, rose, violet)

- **Modèle commercial:** Commission-based

- **Proposition de valeur clé:** Prestataires vérifiés, disponibilité partout en Côte d'Ivoire, avis de confiance

- **Services proposés:** Plomberie, bricolage/rénovation, restauration, hébergement, shopping, transport, immobilier, couture

Tu dois créer un site vitrine (landing page) qui:

1. **Présente MAIDERE de façon claire et attractive** — communique instantanément la mission (connecter clients et prestataires locaux vérifiés) et les bénéfices clés (urgence, proximité, confiance)

2. **Respecte l'identité visuelle de marque** — utilise les couleurs de marque (#1B2A5E, #3DAE2B, avec accents de la palette complémentaire), adopte un design moderne et propre reflétant le logo stylisé M dans une épingle de localisation

3. **Affiche les catégories de services** — présente visuellement les 8 services principaux (plomberie, bricolage, restauration, hébergement, shopping, transport, immobilier, couture) avec icônes claires

4. **Met en avant les points de confiance** — prestataires vérifiés, couverture nationale, système d'avis/évaluations

5. **Inclut les sections essentielles:**

   - Hero section avec slogan et call-to-action (CTA) clairs

   - Explication du fonctionnement (comment ça marche)

   - Galerie/grille des services disponibles

   - Témoignages ou avantages compétitifs

   - Section d'inscription/contact ou CTA pour clients et prestataires

   - Footer avec informations de base

6. **Est responsive et professionnel** — adapté mobile, desktop, design cohérent, performance optimisée

7. **Utilise React, Vite, Tailwind CSS** — technologie stack identique à MAIDERES (le back-office)

Tu dois générer le code complet (HTML/composants React) prêt à être déployé, avec tous les assets nécessaires (images d'icônes, structure de composants, pages statiques intégrées).
